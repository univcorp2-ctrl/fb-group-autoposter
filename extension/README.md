# 物件投稿ヘルパー（Chrome拡張）

Playwright方式が自動化検知/セレクタ崩れで安定しない問題への**別アプローチ**。
Claude in Chrome ではなく**自前の拡張**としてグループページ内（＝実ログインセッション内）で動くため:

- 自動化フィンガープリントが出にくい（本物のブラウザ・本物のセッション）
- Claude in Chrome の「操作ごとの許可」ダイアログが一切出ない
- 投稿は `execCommand('insertText')` でReactが値を認識する形で流し込む

## インストール（初回のみ）
1. Chromeで `chrome://extensions` を開く
2. 右上「デベロッパー モード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」→ この `extension` フォルダを選択

## 使い方
1. グループ `https://www.facebook.com/groups/1281008662437696` を開く（ログイン済み）
2. 右下「🏠 物件投稿ヘルパー」パネルが出る
3. 物件をプルダウンで選択（本文はその場で編集可）
4. **「プレビュー投入」**＝投稿欄に本文を入れるだけ（送信しない）→ 表示確認
5. 問題なければ **「投稿実行」**＝本文投入＋「投稿」ボタン押下まで（確認ダイアログあり）

## 物件の追加
`posts.js` の `window.FB_POSTS` を編集。将来 EstateBoard CSV から自動生成も可。

## うまく動かない時
FB側のDOM変更でボタン検出が外れることがある。その場合は `content.js` の
`findComposerTrigger` / `findDialogEditable` / `findPostButton` のセレクタを調整。
コンソール（F12）のログとパネル下部のログで失敗箇所を特定できる。
